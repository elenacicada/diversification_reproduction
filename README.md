## README: repo "diversification_reproduction" 

## Data, scripts and figures associated with "Traits and hidden states: is self-fertilization associated with rates of diversification across mating and sexual systems?"

### Paper

The preprint associated with this dataset is: 

"Traits and hidden states: is self-fertilization associated with rates of diversification across mating and sexual systems?" Elena M Meyer, Michael S Rosenberg, Bret M Boyd, Andrew J Eckert, Traits and hidden states: is self-fertilization associated with rates of diversification across mating and sexual systems?, biorxiv, 2026, [https://doi.org/10.64898/2026.06.18.733044](url)

### Description of the project

Selfing-fertilization is sometimes described as an evolutionary "dead end." We address this question in a multi-family framework to investigate the generality of these patterns. To this end, we examine how mating system and sexual system traits impact rates of diversification across 18 phylogenetically diverse families. We also leverage the relationship between mating and sexual systems to gain insight into the impact of reproductive biology on evolutionary outcomes.

This project is ongoing, and files and description may be updated. 

#### Files and variable

**Description:** This repository contains the following R scripts. 

* "Workflow4HiSSE.R" - an annotated R script which was used to run HiSSE-type models for binary mating system data (i.e., selfing or non-selfing).
* Workflow4MultiState.R - an annotated R script which was used to run HiSSE-type models for multi-state sexual system data (i.e., a three-category sexual system classification of dioecy, monoecy, or hermaphroditism). 
* BiSSE4SexSyst.R - an annotated R script which was used to run HiSSE-type models for binary-state sexual system data (i.e., family cases in which only two of three possibly sexual systems trait states were present).
